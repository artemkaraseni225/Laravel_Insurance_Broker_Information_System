Insurance Broker Information System

Инновационная информационная система для автоматизации работы страхового брокера. Платформа объединяет полный цикл учета страховых продуктов с модулем интеллектуального анализа на базе NLP для предоставления персонализированных рекомендаций.

Ключевые возможности
Разделение ролей: Изолированные рабочие пространства для клиентов, брокеров и администраторов.

Управление заявками: Полный контроль жизненного цикла заявки от создания до прикрепления документов и выпуска полиса.

Гибкое хранение данных: Использование JSON-структур для хранения специфичных параметров различных типов страхования без усложнения схемы БД.

Финансовый учет: Отслеживание оплат по полисам и автоматический расчет брокерских комиссий.

AI-модуль (в разработке): Обработка естественного языка (NLP) и интеграция с LLM для анализа потребностей и автоматического подбора тарифов.

Технологический стек
Backend: PHP 8+, Laravel, REST API

База данных: MySQL (спроектирована с упором на строгую ссылочную целостность)

Frontend: React, JavaScript

Data Science / AI: Python, NLP
